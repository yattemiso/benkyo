# Fortune Type Site

このプロジェクトは、MBTI診断と運勢占い機能を持つシンプルでかわいいWebサイトです。以下に、プロジェクトの概要と各ファイルの説明を示します。

## プロジェクトの目的

このWebサイトは、ユーザーが自分の性格タイプを診断し、そのタイプに基づいて運勢を占うことができるインタラクティブな体験を提供します。

## ファイル構成

- **index.html**: ホームページで、サイトの説明や各ページへのリンクが含まれています。
- **about.html**: サイトの目的や内容についての詳細な説明が記載されたページです。
- **diagnosis.html**: MBTI診断のインターフェースを提供するページで、ユーザーが質問に答えることでタイプを診断します。
- **fortune.html**: ユーザーが入力したタイプに基づいて今日の運勢を表示するページです。
- **css/style.css**: サイト全体のスタイルを定義するCSSファイルで、かわいくてシンプルなデザインを実現します。
- **js/main.js**: サイト全体の基本的な機能を管理するJavaScriptファイルです。ページ間のナビゲーションや共通の処理を含みます。
- **js/diagnosis.js**: MBTI診断のロジックを実装したJavaScriptファイルで、ユーザーの回答を処理し、診断結果を表示します。
- **js/fortune.js**: 運勢占いのロジックを実装したJavaScriptファイルで、ユーザーが入力したタイプに基づいて運勢を計算し、表示します。
- **docs/processing-notes.md**: 各処理の意図や実装の詳細についての説明が記載されたドキュメントです。

## セットアップ手順

1. このリポジトリをクローンまたはダウンロードします。
2. `index.html`をブラウザで開き、サイトを表示します。
3. 各ページにアクセスして、MBTI診断や運勢占いを体験してください。

## 使用方法

- ホームページから各ページへのリンクをクリックして、診断や運勢占いを行います。
- 各ページには、必要な情報やインタラクションが含まれています。

このプロジェクトを通じて、Web開発の基礎を学び、インタラクティブな体験を提供する方法を探求してください。
