A LITTLE WEB GUIDE 🐻

GitHubを使った
Webサイトのつくりかた

PCで作業するときの、基本的な流れをまとめました。

1. GitHubでリポジトリ（箱）を作る 📦

ブラウザでGitHubを開き、「New」から新しいリポジトリを作ります。

GitHubを開く ↗

※「GitHub Pages」はWebサイトを公開する機能の名前です。 リポジトリを作る場所はGitHubです。

2. GitHub Desktopでパソコンに持ってくる 💻

初回のみ行います。GitHub Desktopを使って、GitHubで作った リポジトリをパソコンにダウンロード（Clone）します。

3. VS CodeとCopilotでページを作る ✏️

VS Codeでリポジトリのフォルダーを開き、Copilotに 「〇〇なサイトを作って」とお願いしながらコードを作成・編集します。

完成した index.html をブラウザにドラッグ＆ドロップして、 見た目や動きを確認します。手元のPC内での確認なので、何度でもやり直せます。

4. GitHub Desktopでネットに送る 🚀

思い通りのサイトができたら、GitHub Desktopで変更内容のメモを書いて Commitし、PushしてGitHubへ送ります。

5. GitHub Pagesで公開する 🌐

初回のみ、GitHubのリポジトリで Settings > Pages を開き、公開設定を行います。

2回目以降は、Step 4のPush後に数分待ってから公開URLを再読み込みすると、 更新が反映されます。

少しずつ試しながら、自分のペースで作ってみましょう 🐹
